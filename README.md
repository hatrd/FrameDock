# FrameDock

Windows 托盘里的轻量视频截图与截取工具。拖入 MKV、MP4，用 `[` / `]` 去头去尾，`C` 锁定封面，`Shift+D` 一起导出片段与 PNG。

## 使用

1. 需要 Windows x64 与 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)。运行 `FrameDock.exe`，拖入视频到窗口。
2. 下方白色指针定位画面，上方绿色 `[` / 橙色 `]` 手柄拖动边界；即使边界与播放指针重合也能分别拖动。`H/L` 或左右箭头逐帧，`J/K` 或上下箭头跳一秒，空格播放/暂停。定位、逐帧和设置边界时自动暂停。
3. 时间轴滚轮以鼠标所在时间为中心缩放；`Shift+滚轮`、右键或中键拖动平移。底部全片总览可拖动视角。`F` 放大选段，`0` 恢复全片视图，均保留边界。放大后拖指针/边界到左右边缘会自动滚动。
4. 在要保留的第一帧按 `[` 设置起点，在终点按 `]`。`Home` 或 `Shift+[` 跳到当前起点，`End` 或 `Shift+]` 跳到当前终点，跳转时自动暂停并显示对应位置，不改变边界。`R` 试听选段并在终点自动暂停。“重置范围”恢复整段视频。
5. 找到封面画面按 `C`，缩略图和时间会显示已锁定。之后移动指针、修改边界或切换字幕不会改变该封面；再次按 `C` 替换。“清除封面”恢复使用当前画面。
6. `Shift+D` 将片段与已选封面加入后台队列，PNG 文件名以片段名开头并包含封面时间。未选封面时使用当前画面。`D` 只导出片段，`S` 只导出已选封面（未选时用当前画面）；`Shift+S` 始终保存当前画面，不改变锁定封面。截图保持源分辨率和拍摄时的字幕状态。
7. 默认勾选“纯复制”：自由设置边界，界面单独显示预计复制起点，导出从前一个可复制切点开始，可能多留一小段头部。**需要准确去头时取消勾选**，改用精确切割并重新编码视频，音频尽量复制。显示字幕与纯复制冲突时会给出选择。
8. 关闭窗口缩回托盘；再打开时恢复视频和位置。托盘“退出”会在有任务时提示等待或取消。“开机时启动”默认关闭。

按 `F1` 或点击“快捷键总览”查看全部快捷键及时间轴鼠标操作；总览为只读，按 `Esc` 关闭，未打开视频时也可查看。快捷键仅在 FrameDock 窗口中生效；音轨、字幕、预览下拉框和并发输入框保留自己的键盘操作。导出期间可以继续编辑，队列保存提交时的边界和封面。

文件保存在源视频目录。文件名包含范围、音轨、字幕和模式；相同片段已完成且通过源范围、视频包、解码画面及音轨检查时只显示原文件路径。若同名片段未通过验证，程序会将其改名为 `.invalid-...`，显示保留路径并重新生成。

## 构建

在此目录运行 `dotnet build FrameDock/FrameDock.csproj`。开发时会查找 `C:\Users\R\Tools\mpv\player\mpv.exe`，也可设置 `FRAMEDOCK_MPV` 指向其他 mpv.exe。FFmpeg 与 ffprobe 从程序目录、PATH 或 WinGet 安装目录查找。

运行 `./publish.ps1` 生成 `artifacts/win-x64`，脚本把 mpv.exe 附到发布包。可通过 `-MpvExe` 和 `-Output` 指定其他路径。不要只复制 FrameDock.exe；发布包内的 mpv.exe 也需要一起复制。

时间轴回归：`dotnet run --project tests/TimelineRegression -c Release`。程序在 `artifacts/timeline-regression` 创建独立测试目录，生成 MP4/MKV、长 GOP、B 帧、非零时间原点、静音、短片段、可变帧率和字幕素材；通过实际导出器、成品验证器与无声音的 mpv IPC 检查首尾范围、切点和判重。第二个参数可指定真实视频；默认还检查本机审计中使用的视频（存在时）。每次运行保存 `results.json` 和导出片段。修复规则见 [时间轴修复记录](docs/diagnostics/2026-09-30-timeline-fix.md)。

交互回归：`dotnet run --project FrameDock.Tests -c Release`。需要 mpv、FFmpeg 和桌面会话；会短暂打开测试窗口，在 `.scratch/interaction-test` 生成两分钟视频，检查重合手柄、缩放/平移、精确定位、边界与复制切点分离、锁定封面、片段与封面实际导出、快速连续寻址、试听自动停止和最小窗口布局。

## 已知边界

- 只处理文件内嵌字幕，不加载外挂字幕。
- 纯复制切片受关键帧、音频包和容器时间戳约束；界面显示预计范围，实际成品可能差几个包。
- 画入字幕必须重编码视频。某些图片字幕或特殊编码组合可能被 FFmpeg 拒绝，任务会显示失败原因。
- 精确模式默认把 H.264/H.265 分别编码为 H.264/H.265；其他视频编码目前输出 H.264。
- 成品检查要求所选范围内的实际画面完整、视频和音轨保持同一时间换算；纯复制逐包核对源内容 SHA-256，精确模式核对每帧时间及首尾缩小画面的编码差异。首尾检查包含所选画入字幕；字幕在中间每帧上的视觉质量仍需人工检查。
- 时间戳缺失、损坏或无法与源内容核对的输入会报告失败。验证需要读取源包并解码画面，导出及既有片段复用会比只查容器时长慢。
