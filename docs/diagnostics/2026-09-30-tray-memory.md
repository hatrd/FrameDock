# 托盘资源释放验证

本次验证基于 `c3dd82e`（边界跳转与快捷键总览）及品牌图标、窗口恢复、托盘资源优化。首次验证时用户要求暂停发布；补充真实界面截图、精简 README 后，用户重新授权发布 v1.0.0。

## 释放行为

关闭窗口后，停止试听、取消并等待可复制切点扫描结束，等待正在进行的定位或封面读取完成，再退出 mpv，释放其解码缓存、IPC 与视频文件句柄。视频加载、托盘恢复与关闭操作串行处理，避免关闭过程中又创建隐藏播放器。

托盘保留范围、位置、音轨／字幕设置、切点信息、锁定封面的压缩 PNG 与小缩略图。缩略图最大为控件尺寸的两倍，不保留源尺寸解码位图。空闲约 1.5 秒后做一次完整、压缩的托管堆回收，归还不用的堆空间；未使用工作集裁剪 API。

尚有导出任务时，FFmpeg／ffprobe 仍按任务需要读取视频和占用资源，任务完成后再进行空闲回收。

## 方法与结果

`dotnet run --project FrameDock.Tests -c Release`：**146 项通过**。除了已有交互／导出／窗口布局检查，还验证新合入的 `Shift+[` / `Shift+]` 跳转，使用 1920×1080、30 fps、8 秒的合成视频循环打开／缩回托盘 20 次。

每轮验证 mpv 进程退出、切点扫描任务结束、源视频可独占打开、封面与边界保留；并发唤出后恢复第 3 秒画面且保持暂停。另测关闭发生在视频加载过程中，不会遗留隐藏播放器。

最终一次完整回归的采样（MiB；测量的是运行实际 MainForm 的测试宿主，不是单独启动的发布 EXE）：

| 状态 | 宿主私有内存 | 宿主工作集 | mpv 私有内存 | 托管堆 |
| --- | ---: | ---: | ---: | ---: |
| 第 2 次托盘闲置 | 24.47 | 85.48 | 0 | 2.28 |
| 第 20 次打开预览 | 21.89 | 84.71 | 233.45 | 2.39 |
| 第 20 次托盘闲置 | 22.63 | 85.46 | 0 | 2.25 |

表内闲置采样包含应用自身的单次回收，没有测试侧强制回收。末尾另外进行保留对象审计，托管堆为 2.22 MiB。20 次循环没有持续累积视频大小的内存；.NET／WinForms 自身仍有运行时与共享页占用。分辨率、封面内容、长视频切点数量和导出任务会影响实际数值。

详细采样在 `.scratch/tray-memory/results.json`；运行日志在 `.scratch/interaction-test/full-test.log`。独立复测命令：

```powershell
dotnet run --project FrameDock.Tests -c Release -- --tray-memory
```

时间轴／导出回归：`dotnet run --project tests/TimelineRegression -c Release`，**66 项通过，0 失败**；结果在 `artifacts/timeline-regression/20260930-081646/results.json`。

## 图标验证

品牌标识为青绿色 F、琥珀色右截取边界与深蓝圆角底。ICO 包含 16、20、24、32、40、48、64、128、256 px 九个 32 位 DIB 图层。采用 DIB 避免小尺寸 PNG 图层在 System.Drawing.Icon.ToBitmap 中解码异常；已检查浅色／深色背景上的小尺寸显示，并从构建后的 EXE 提取图标核对。主窗口、托盘及新合入的快捷键总览共享品牌标识。
